WHAT YOU GET

자동 마스터 한 번에서 끝나지 않습니다.

Professional은 자동 처리 결과를 기준으로 판단하고, 필요한 부분만 깊게 손보고, 납품 가능한 파일까지 완성하는 전체 작업 흐름을 제공합니다.

01 · AUTO MASTER

One Click + Final Audit

분석 → 설정 → 렌더 → 검사 → Final을 한 번에 수행합니다. 목표 LUFS만 억지로 맞추기보다 음질 보호를 우선하는 자동 마스터 흐름입니다.

02 · MANUAL MASTER

Quick + Expert Control

LOW, VOCAL, AIR 같은 빠른 조절부터 7-Band EQ, Dynamics, Stereo, Effect까지 직접 설정한 값을 최종 렌더에 반영합니다.

03 · REFERENCE ASSIST

참고곡을 복사하지 않고 판단

상업 레퍼런스와의 톤·음량·스테레오 차이를 분석해 안전 범위의 가이드로 제시합니다.

04 · PROJECT SYSTEM

저장하고, 불러오고, 되돌리기

Project, User Preset, Auto Save, Undo/Redo, Recover Last Session을 통해 반복 작업과 수정 이력을 관리합니다.

05 · A/B MONITOR

같은 위치에서 Original / Final 비교

재생 위치를 맞춘 A/B 비교와 Level Match로 단순히 큰 소리가 더 좋아 들리는 착시를 줄이고 결과를 판단합니다.

06 · PRO DELIVERY

마스터링 이후의 납품까지

WAV, MP3, AAC, Metadata, Cover Art, Preflight, ZIP을 하나의 워크플로우에서 준비합니다.

EXPERT MASTERING

Professional이 필요한 이유는
세밀한 판단 영역에 있습니다.

EQ

Expert 7-Band EQ

전체 음색을 한두 개의 톤 노브로만 바꾸지 않고, 주파수 영역별로 필요한 만큼 조절해 밸런스를 잡습니다.

DH

De-Harsh / Dynamic EQ

고역의 거친 자극이나 특정 대역의 과도한 움직임을 정리하는 전문가 보정 레이어입니다.

DY

Dynamics / Multiband

곡 전체의 밀도와 펀치를 다루면서 과도한 압축으로 트랜지언트와 공간감이 무너지지 않도록 조절합니다.

ST

Stereo Width / Low Mono

저역의 중심을 안정시키고 필요한 대역의 폭만 조절해 넓지만 불안정하지 않은 스테레오 이미지를 만듭니다.

RA

Reference Assist

레퍼런스를 그대로 복제하지 않고, 현재 믹스가 어느 방향으로 다른지 판단할 수 있도록 보조합니다.

QA

Final Audit / Preflight

True Peak와 최종 레벨뿐 아니라 전달 단계에서 놓치기 쉬운 항목을 마지막에 다시 확인합니다.

FAQ

자주 묻는 질문

ONLINE을 구독하면 Professional도 사용할 수 있나요?

ONLINE 정기구독과 Professional 디지털 라이선스는 별도 상품입니다. ONLINE은 웹 서비스 이용과 다운로드 권한을, Professional은 Windows용 전문 워크스테이션 라이선스를 제공합니다.

Professional도 자동 마스터링이 되나요?

네. AUTO MASTER · ONE CLICK으로 기본 마스터를 빠르게 만들 수 있으며, 필요할 때만 Manual / Expert 기능으로 세밀하게 조절할 수 있습니다.

전문가 기능을 몰라도 사용할 수 있나요?

가능합니다. 처음에는 AUTO MASTER와 기본 Loudness Target만 사용하고, 익숙해진 뒤 Reference Assist, EQ, Dynamics, Stereo 기능을 추가로 사용하면 됩니다.

인터넷이 없으면 실행할 수 없나요?

라이선스 검증 이후 일정 기간 사용할 수 있도록 14일 Offline Grace 구조를 적용합니다. 장기간 오프라인 환경에서는 재검증이 필요할 수 있습니다.

몇 대의 PC에서 사용할 수 있나요?

Professional 라이선스는 최대 2대의 PC 활성화를 기준으로 구성되어 있습니다.
