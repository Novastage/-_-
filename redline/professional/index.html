WHY PROFESSIONAL?

“내가 왜 Professional을 써야 하지?”
이 질문에 답하는 기능들.

빠른 자동 마스터 한 번이면 충분한 사용자도 있습니다. Professional은 한 곡을 반복해서 판단하고 수정해야 하는 순간부터 가치가 생깁니다.

01

귀로만 듣지 않는다

Original / Final을 같은 위치에서 A/B하고 Waveform, Level Match, Analyzer를 보면서 차이를 확인합니다.

02

숫자로 다시 검증한다

LUFS, True Peak, Crest, Stereo Correlation과 Final Audit를 통해 최종 결과를 점검합니다.

03

AUTO 이후 직접 손본다

7-Band EQ, Dynamic EQ, De-Harsh, Multiband, Stereo Width, Low Mono를 필요한 만큼만 조정합니다.

04

작업을 저장하고 이어간다

Project, User Preset, Undo/Redo, Auto Save, Session Recovery로 수정 이력을 관리합니다.

05

레퍼런스로 방향을 잡는다

Reference Assist가 톤·음량·스테레오 차이를 가이드해 감에만 의존하는 판단을 줄입니다.

06

납품까지 끝낸다

WAV, MP3/AAC, Metadata, Cover Art, Preflight, ZIP Delivery까지 하나의 작업 흐름으로 연결합니다.

SEE + HEAR

파형 모니터링과 A/B가 중요한 이유.

마스터링은 “소리가 좀 커졌다”만으로 판단하면 안 됩니다. 같은 구간에서 Original과 Final을 번갈아 듣고, Level Match로 음량 착시를 줄이고, Stereo Waveform과 Analyzer를 함께 보면서 변화가 어디서 생겼는지 확인해야 합니다.

Original / Final 동일 위치 비교같은 음악 구간에서 차이를 바로 확인합니다.
Level Match더 큰 소리가 더 좋게 들리는 착시를 줄입니다.
Live Signal Monitor좌/우 신호 흐름과 스테레오 움직임을 시각적으로 확인합니다.
Spectrum / Spectrogram / Peak Hold문제가 어느 주파수에서 발생하는지 청감과 함께 판단합니다.
MEASURE BEFORE GUESSING

LUFS와 True Peak를
“감”이 아니라 수치로.

Professional은 SOURCE, TARGET, FINAL의 Loudness를 구분하고 True Peak를 함께 확인합니다. AUTO MASTER 역시 목표 숫자를 억지로 맞추기보다 과도한 리미팅이 감지되면 품질 보호를 우선할 수 있습니다.

Source / Target / Final LUFS-I현재 음량과 목표, 최종 결과를 분리해서 확인합니다.
True Peak Ceiling인코딩 이후 발생할 수 있는 인터샘플 피크까지 고려합니다.
Genre / Character + Quick Control자동 판별을 기본으로 LOW / VOCAL / AIR를 필요한 만큼 조절합니다.

Undo / Redo / Recovery조절 이력을 되돌리고 마지막 세션을 복구합니다.
AUTO IS THE STARTING POINT

자동으로 시작하고,
최종 결정은 직접.

AUTO MASTER · ONE CLICK은 분석부터 Final Audit까지 빠르게 진행합니다. 하지만 곡마다 필요한 마지막 5%는 다릅니다. 그때 Manual Master가 현재 Quick / EQ / Dynamics / FX 설정을 실제 최종 파일에 반영합니다.

AUTO MASTER · ONE CLICK분석 → 렌더 → 검사 → Final을 자동 수행합니다.
SOURCE ANALYZE원본의 Peak, Crest, Stereo 등 핵심 상태를 먼저 확인합니다.
MANUAL MASTER사용자가 조절한 Expert 값을 최종 렌더에 반영합니다.
EXPERT CONTROL

Professional의 핵심은
자동 이후의 선택권입니다.

모든 기능을 매번 사용할 필요는 없습니다. 문제가 있는 부분만 필요한 만큼 개입할 수 있다는 것이 Online과 다른 지점입니다.

7-BAND EQ

주파수별 톤 조절

45 Hz부터 12 kHz까지 필요한 영역만 작게 보정해 전체 밸런스를 세밀하게 다룹니다.

DYNAMIC EQ / DE-HARSH

문제가 생길 때만 반응

거친 고역이나 특정 대역이 튀는 순간에만 보정해 정적인 EQ보다 자연스럽게 정리합니다.

MULTIBAND DYNAMICS

대역별 밀도와 펀치

4-band compression과 Master Compressor로 저역부터 고역까지 움직임을 별도로 제어합니다.

STEREO / LOW MONO

넓지만 불안정하지 않게

Stereo Width와 Low Mono를 이용해 공간감을 유지하면서 저역 중심을 안정시킵니다.

REFERENCE ASSIST

복제가 아닌 방향 제안

상업 레퍼런스의 톤·음량·스테레오 차이를 분석해 안전 범위의 가이드로 제시합니다.

FINAL AUDIT / PREFLIGHT

마지막 실수를 줄이기

마스터의 레벨과 납품 규격을 최종 단계에서 다시 확인한 뒤 Delivery 파일을 만듭니다.

ONLINE이면 충분한 경우

빠르게 한 곡을 처리하거나, 설치 없이 여러 PC에서 접근하거나, STEM / VOICE CLEAN / AI RESTORE가 주요 목적이라면 ONLINE이 더 간단합니다.

  • 마스터 결과를 빠르게 만들고 싶다
  • 세부 EQ/Dynamics 조정은 거의 하지 않는다
  • 프로젝트 저장/납품 패키지가 필요하지 않다
  • 브라우저 기반 작업이 더 편하다

PROFESSIONAL이 필요한 경우

곡을 반복 수정하고, 시각적 모니터링과 세밀한 보정을 하며, 레퍼런스와 프로젝트를 관리하고 최종 납품까지 책임져야 한다면 Professional 쪽이 맞습니다.

  • 파형 / Analyzer / Level Match로 확인하고 싶다
  • AUTO 결과를 직접 미세 조정하고 싶다
  • 앨범·싱글 프로젝트를 저장하고 다시 열고 싶다
  • WAV 이후 Preflight / Codec / ZIP까지 필요하다
