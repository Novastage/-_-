마스터링으로 돌아가기정기구독
USER GUIDE

온라인 마스터링
사용법

파일을 불러온 뒤 분석 → 자동 마스터링 → Original/Master 비교 → 최종 출력 순서로 사용합니다. Professional에서 검증된 AUTO MASTER 엔진을 온라인 서버에 연결한 뒤에도 이 기본 작업 흐름은 그대로 유지합니다.

무료 사용자: 마스터 결과를 최대 60초까지만 미리 듣고 다운로드는 사용할 수 없습니다. 정기구독 사용자: 전체 길이 마스터링, 곡 수 무제한, 전체 기능 및 최종 파일 다운로드를 사용할 수 있도록 구성합니다.
01 · SOURCE

원본 음원 불러오기

WAV, AIFF, FLAC, MP3 등 원본 믹스를 선택합니다. 가능하면 최종 믹스 WAV를 권장합니다.

02 · ANALYZE

자동 분석

LUFS, Peak, True Peak, Crest, Stereo 상태와 소스 특성을 분석하고 자동 마스터링의 기준값을 결정합니다.

03 · TARGET

장르와 목표값 확인

장르/Character와 Loudness Target을 확인합니다. 기본값은 안전한 스트리밍 기준으로 시작하고 필요할 때 조정합니다.

04 · AUTO MASTER

자동 마스터링 실행

Professional에서 검증된 자동 마스터링 메커니즘과 동일한 처리 순서 및 수치를 서버 엔진에서 적용하도록 구성합니다.

05 · A/B

Original / Master 비교

같은 재생 위치에서 원본과 마스터 결과를 번갈아 들어 음량뿐 아니라 저역, 보컬, 고역, 다이내믹과 스테레오 변화를 확인합니다.

06 · FINE CONTROL

필요 시 세부 조정

LOW, VOCAL, AIR, 7-Band EQ, De-Harsh, Stereo Width 같은 세부 조절 기능을 사용합니다. 자동 마스터만 사용할 경우 기본값 그대로 진행할 수 있습니다.

07 · PREVIEW

무료 60초 미리듣기

구독하지 않은 사용자는 마스터 결과 중 최대 60초만 음질 확인용으로 재생할 수 있으며 다운로드 버튼은 잠깁니다.

08 · DOWNLOAD

구독자는 전체 곡 다운로드

정기구독 상태가 확인되면 전체 길이 마스터링과 다운로드가 활성화되고 곡 수 제한 없이 사용할 수 있도록 합니다.

권장 사용 순서

소스 선택 → Analyze → Auto Master → A/B 비교 → 필요 시 세부 조정 → Final Audit → 구독자는 최종 WAV 다운로드. 무료 사용자는 60초 Preview까지만 제공됩니다.
